# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-02-07

### Added
- Initial Flutter application setup
- Master List task management functionality
- Add items feature with text input and button
- Mark items as complete/incomplete with checkboxes
- Delete items functionality with trash icon
- Empty state message when no items exist
- Material Design 3 UI with deep purple theme
- Comprehensive widget tests
- Cross-platform support (Android, iOS, Web, Desktop)
- Project documentation (README, DOCUMENTATION, VISUAL_GUIDE)
- MIT License
- .gitignore for Flutter projects
- Analysis options with flutter_lints

### Features
- Clean and intuitive user interface
- Responsive design for all screen sizes
- Keyboard support (Enter to add items)
- Visual feedback for completed items (strikethrough, grey text)
- Immediate UI updates with setState()

### Technical
- Flutter SDK 3.0.0+ compatibility
- Material Design 3 theming
- StatefulWidget architecture
- TextEditingController for input management
- ListView.builder for efficient rendering
